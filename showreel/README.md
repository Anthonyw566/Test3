# Showreel — a film made entirely from code

A 32.5-second, 1920×1080, 30 fps film **with a full soundtrack and sound design**, where every pixel and
every sound is generated by code in this folder. No camera, no stock footage, no audio samples, no
video-generation model — just JavaScript that draws each frame and synthesizes each sound.

`out/showreel.mp4` is the film. `out/soundtrack.mp3` is the audio on its own. `stills/` has four
frames pulled from the same renderer (image generation, same method).

## What's in it

| Time | Scene | What's happening |
|------|-------|------------------|
| 0:00 | Open | Typographic title card, drifting dust, hairlines drawing outward |
| 0:05 | Gauge | A procedurally drawn brass gauge. The needle is a real spring simulation chasing a ramp, and it counts the film's own frames |
| 0:12 | Knot | 5,200 particles spiral in a vortex, then collapse onto a rotating (2,3) torus knot with bloom and shockwaves |
| 0:20 | Code | The source of the needle simulation types itself out, syntax-highlighted, then a build terminal runs |
| 0:27 | Finale | Count-up of the film's real stats (frames, pixels, audio samples), then the title |

## The sound

All synthesized in `audio/synth.js` — oscillators, noise, filters, a Freeverb and a ping-pong delay.
Music is a Dm9 → Bbmaj7 → Gm9 → A7sus4 progression at 96 BPM with scenes cut on bar lines. The sound
design is locked to the picture because both read one clock (`src/shared.js`):

- **Ratchet clicks** are the needle actually crossing tick marks in the spring simulation (105 of them), pitched up as the needle climbs
- **Servo whine** follows the needle's real velocity
- **Keystrokes** are the characters you see typed in the code scene
- **Impacts** land on the cut frames; the **lock-in hit** lands on the exact frame the knot snaps shut
- Risers, reverse cymbals, whooshes, counter ticks, bells, a sidechain-ducked pad, and a short silence before the drop at 0:12.5

Mastered to about −15 LUFS with a true peak of −2.6 dBTP measured on the final AAC; no clipped samples.

## Rebuild it

Needs `node` (22+), `ffmpeg`, and `playwright` with Chromium.

```sh
./build.sh                 # synth -> render all frames -> encode out/showreel.mp4
node audio/synth.js out/x.wav                         # just the soundtrack
node render.js --list=340,570 --png --dir=stills      # just a couple of stills
open src/scene.html?live                              # live preview in a browser (no audio)
```

`render.js` runs four headless-Chromium workers in parallel. That works because
`renderFrame(n)` is a pure function of the frame number: no accumulated state.

## Files

- `src/shared.js` — the shared clock: timeline, scene list, needle spring, typing schedule, event times
- `src/scene.js` — all drawing (Canvas 2D)
- `src/scene.html` — the page that hosts it, plus the fonts
- `audio/synth.js` — the soundtrack and every sound effect
- `render.js` — frame renderer and ffmpeg encoder
- `fonts/` — DM Serif Display, DM Sans, JetBrains Mono (SIL OFL)

## Honest notes

- The audio was checked by measurement (loudness, clipping, spectrogram, level jumps at each cut), not by ear.
  Mix balance is a judgement call you may want to adjust; the gains are plain numbers at the top of each cue in `synth.js`.
- The video uses a deliberately high bitrate (CRF 15, capped at 24 Mbit/s) because animated film grain is expensive to compress.
