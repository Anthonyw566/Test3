# Distant Frontiers: procedural trailer

A 65-second cinematic trailer for this mod. **Every pixel and every sound is generated by code.**
It uses no footage, no stock images, no audio samples and no image, video or audio AI models.
The picture is shaders and canvas drawing. The score and sound design are synthesized from sine
waves, sawtooths and noise.

## How it's built

```
timeline.json        one cue sheet: scenes, ring data, Heat steps, champion names, beat-aligned cue times
render/              the picture: a WebGL2 + Canvas 2D "stage" page
  shaders.js         terrain raymarcher, hearth/map, crinkle panel, smoke, compositor and post
  scenes/*.js        one module per sequence; each draws frame t and returns post settings
render.mjs           drives the stage in headless Chromium frame by frame, piping PNGs into x264
audio/synth.py       synthesis toolkit (oscillators, physical models, filters, reverb, mastering)
audio/score.py       the score and sound design, composed against timeline.json
build.sh             score → picture → mux
```

**One clock.** The edit is cut to a 96 BPM bar grid (1 bar = 2.5 s). The renderer and the score
read the same `timeline.json`, so every border crossing lands on a downbeat and every Heat jump
lands on a beat. Moving a cue moves its picture and its sound together. Frames are pure functions
of `t = frame / fps` and never read a wall clock. Any frame can be rendered alone, which is what
lets `render.mjs` split the film across workers.

**Picture**
- *Terrain.* A raymarched heightfield using derivative-damped value noise (an "eroded" fBm). Its
  character depends on distance from spawn and uses the mod's real ring radii: meadows at home,
  carved ridges in the Wildmarch, basalt with glowing Voronoi lava seams in the Ashenfront.
  Detail falls off with distance through fractional octaves, so there are no LOD seams. Overshoots
  get a secant refinement, so ridgelines don't stair-step.
- *Camera that never clips.* The flight path is carved into the terrain as a valley. The camera's
  altitude comes from a **bit-identical JavaScript copy** of the shader's height function. Both read
  the same 256×256 lattice table, so the CPU knows exactly what the GPU draws.
- *Ring borders* are ray–circle intersections around spawn, drawn as shafts of light in the next
  ring's colour. The Wildmarch's watching eyes are 3D points depth-tested against the terrain, so
  hills hide them correctly.
- *Post.* HDR composite, dual-Kawase bloom, a film-style highlight shoulder that keeps UI colours
  true, lift/gamma/gain grading, luminance-weighted grain, radial chromatic aberration, a swirl/pinch
  lens warp (the Warper), shake and letterbox.
- *Gauge.* The needle is a superposition of damped-spring step responses, one per Heat jump, so it
  overshoots and settles like a real movement with no simulation state.
- *Type.* Cormorant Garamond, IM Fell English (the expedition-journal voice), IBM Plex Mono for
  data and Playfair Display for lining figures. Reveals are per-glyph blur-to-sharp with tracking
  that tightens; names decode on a fixed glyph grid so the layout never jumps.

**Sound.** `audio/synth.py` builds everything from scratch:
- *Instruments.* PolyBLEP band-limited saws and supersaws, Karplus–Strong plucked strings
  (vectorized a period at a time, resampled for exact pitch), Risset additive bells, synthesized
  taiko, braams, a choir made from formant-filtered saws, and a Shepard–Risset glissando.
- *Effects.* Fire (Poisson-timed crackles over a brown-noise roar), wind, glass shards, crumbling
  stone, FM teleport zaps, a flanged portal, and a growl.
- *Space and dynamics.* A synthetic-impulse convolution reverb with frequency-dependent decay and
  sidechain ducking under hits.
- *Mastering.* Tone EQ, glue compression, ITU-R BS.1770 loudness normalization to −14 LUFS and a
  lookahead limiter at −1 dBFS.

## Build it

Needs Node 18+, Python 3.10+ and ffmpeg. No GPU is needed: Chromium falls back to SwiftShader.

```
./build.sh                          # full film -> distant-frontiers-trailer.mp4
python3 audio/score.py              # just the soundtrack (≈15 s)
node render.mjs --still 19 44.2     # PNG stills at those times -> out/stills/
node render.mjs --from 35 --to 45   # render one sequence
```

On a 4-core CPU with no GPU, terrain frames take about 3 s each and everything else under 1.5 s,
so a full render takes roughly an hour. On a machine with a real GPU it's minutes.
