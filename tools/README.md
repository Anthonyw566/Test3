# Asset tools

Everything in `resourcepack/` and `media/` is generated by these scripts. No
samples, stock art or recordings: oscillators, filters and hand-placed pixels.

| Script | Makes |
|---|---|
| `make_sounds.py` | 15 sound effects → `resourcepack/assets/distantfrontiers/sounds/` (mono OGG) |
| `make_art.py` | icons, ring emblems, title flipbook frames, `pack.png` → `resourcepack/` |
| `make_trailer.py` | `media/trailer.mp4` (uses the two scripts above for its art and audio) |
| `make_arena.py` | the in-game test arena structure |

Setup once:

```
python3 -m venv .venv && .venv/bin/pip install numpy scipy pillow soundfile imageio-ffmpeg
```

Run from the repo root:

```
.venv/bin/python tools/make_sounds.py --preview sounds.png   # spectrogram sheet to eyeball
.venv/bin/python tools/make_art.py --preview art.png         # 6x preview sheet
.venv/bin/python tools/make_trailer.py                      # ~1 minute
```

If you change the art layout, keep `fx/Glyphs.java` in sync - `make_art.py`
prints the code-point table it wrote. The pack zip is built by Gradle
(`./gradlew resourcePackZip`) and is byte-for-byte reproducible, so its SHA-1
only changes when the assets do.
