# Asset tools

Everything in `resourcepack/` is generated by these scripts. No samples,
stock art or recordings.

| Script | Makes |
|---|---|
| `make_sounds.py` | the pack's few soft sounds → `resourcepack/assets/furtherout/sounds/` (mono OGG) |
| `make_pack_icon.py` | `resourcepack/pack.png` |
| `make_arena.py` | the in-game test arena structure |

Most of the mod deliberately uses vanilla sounds (`fx/Sfx.java`); the pack
only adds sounds vanilla has no good match for, and each one has a vanilla
fallback for players who decline it.

Setup once:

```
python3 -m venv .venv && .venv/bin/pip install numpy scipy pillow soundfile
```

Run from the repo root:

```
.venv/bin/python tools/make_sounds.py --preview sounds.png   # spectrogram sheet to eyeball
.venv/bin/python tools/make_pack_icon.py
```

The pack zip is built by Gradle (`./gradlew resourcePackZip`) and is
byte-for-byte reproducible, so its SHA-1 only changes when the assets do.
